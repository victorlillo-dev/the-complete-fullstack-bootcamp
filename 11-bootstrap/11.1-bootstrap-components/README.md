# Bootstrap Components

Laboratorio realizado durante el módulo de Bootstrap del curso
**The Complete Full-Stack Web Development Bootcamp**.

## Conceptos practicados

- Sistema de grilla de Bootstrap
  - `container`
  - `row`
  - `col`
  - columnas responsivas
  - breakpoints `sm`, `md`, `lg` y `xl`
- Buttons
  - `btn`
  - variantes como `btn-primary`, `btn-success` y `btn-outline-secondary`
- Cards
- Navbar responsive
  - `navbar-expand-*`
  - menú colapsable
  - `data-bs-toggle`
  - `data-bs-target`
- Hero
- Features
- Bootstrap Icons y SVG
- Carousel
- Footer
- Utilities de espaciado
  - margin: `m`, `mt`, `mb`, `mx`, `my`
  - padding: `p`, `pt`, `pb`, `px`, `py`
- Responsive utilities
- Dark Mode con `data-bs-theme="dark"`

## Laboratorio final

`index.html` integra los distintos componentes estudiados en una sola página:

Navbar → Hero → Features → Carousel → Card → Footer

El laboratorio combina componentes Bootstrap con pequeñas personalizaciones
mediante CSS propio.

## Objetivo

Comprender cómo Bootstrap permite construir interfaces responsive reutilizando
componentes, clases utilitarias y breakpoints, y cómo estos elementos pueden
personalizarse para crear una página propia.
