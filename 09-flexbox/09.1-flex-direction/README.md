# Flex Direction

Ejercicio realizado durante el módulo de Flexbox.

## Conceptos practicados

- `display: flex`
- `display: inline-flex`
- `flex-direction`
- Eje principal y eje transversal
- `flex-basis`
- Combinador de hijos directos `>`
- Selector universal `*`

## Objetivo

Organizar los elementos flexibles verticalmente y asignarles un tamaño de
100 píxeles sobre el eje principal.
